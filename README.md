## Reports

### Assignment 1 — Network Penetration Testing
**5 hosts · 3 subnets · 15/15 flags** 

Multi-subnet black-box assessment. Techniques: EternalBlue, SQL injection, DNS zone transfer, Dirty COW, Python pickle deserialization RCE, and dual Meterpreter pivot paths into isolated internal subnets.

### Assignment 2 — Active Directory Penetration Testing
**1 Domain Controller · 2/2 flags** 

Full AD compromise from unauthenticated access. Techniques: Anonymous LDAP enumeration, AS-REP Roasting, Kerberoasting, BloodHound ACL abuse, DCSync, and Pass-the-Hash via evil-winrm.
